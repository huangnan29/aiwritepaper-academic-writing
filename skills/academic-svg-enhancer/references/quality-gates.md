# SVG 出版质量门

## 结构正确

- 节点、关系、方向、基数、状态和术语与来源逐项一致。
- 图中每个视觉编码都能解释；没有仅为装饰而添加的箭头、颜色、图标或区域。
- 图题与正文对图的解释一致，没有图中出现、正文从未定义的新概念。

## 布局与可读性

- 主阅读顺序在 3 秒内可识别。
- 没有文字溢出、节点重叠、连线穿字、箭头遮挡、异常空白或不必要的交叉线。
- 在最终论文栏宽与 100% 缩放下，最小文字和细线仍清晰。
- 图在灰度打印和常见色觉缺陷模拟下仍能区分主要类别。
- 页面背景、边框和留白与整篇论文一致，不出现单张深色主题或网页仪表盘风格。

## 文件与渲染

- SVG 可解析，包含 `viewBox`、`title` 和 `desc`，不依赖远程资源。
- 浏览器、SVG 渲染器和最终 DOCX/PDF 中至少抽查两种渲染结果。
- 导出的 PNG 没有裁切、模糊、透明背景变黑或字体替换；有效分辨率达到 300 DPI。
- 文件名、图号、manifest、正文引用和图注一一对应。

## 失败处理

任一结构错误为 `FAIL`。只有格式或局部排版问题且已记录修复计划时可标记 `PARTIAL`。未经实际渲染检查不得标记 `PASS`。
