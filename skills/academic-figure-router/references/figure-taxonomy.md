# 学术配图分类与攻略

| 图类 | 首选路径 | 关键攻略 | 禁止做法 |
| --- | --- | --- | --- |
| 研究流程、业务流程、算法流程 | 有图片能力：详细 Prompt + 图片生成；无图片能力：SVG | 先定义起止、步骤、判断、回路和异常路径；Prompt 逐字列出节点与每条边；生成后逐项核对 | 一句主题直接生图、遗漏节点或静默回退 SVG |
| 组织架构、模块分解 | 有图片能力：详细 Prompt + 图片生成；无图片能力：SVG | 自上而下，同层同尺寸，Prompt 明确汇报线、协作线、层级和逐字名称 | 用面积或颜色暗示不存在的权重 |
| 软件架构、部署、网络拓扑 | 有图片能力：详细 Prompt + 图片生成；无图片能力：C4/PlantUML/SVG | 分层、边界、协议、数据流分开表达；Prompt 逐项固定组件和连接；一张图只讲一个视角 | 把代码目录树当系统架构图 |
| 数据库 ER 图 | 有图片能力：schema 契约 + 详细 Prompt + 图片生成；无图片能力：Mermaid ER/PlantUML/SVG | 依据真实 schema；Prompt 逐项固定实体、字段、主外键、基数和可空性；实体过多时拆分 | 根据正文想象表和关系 |
| UML 用例、类、状态、时序 | 有图片能力：语义契约 + 详细 Prompt + 图片生成；无图片能力：PlantUML/Mermaid/SVG | 严格遵守对应图法；Prompt 明确参与者、消息、守卫和时间方向；生成后逐项核验 | 混用图法或省略关键参与者 |
| 研究框架、概念模型、因果图 | 有图片能力：详细 Prompt + 图片生成；无图片能力：SVG/Graphviz | 区分构念、观测变量、假设方向、调节和中介；Prompt 固定每条关系并回到文献或研究假设 | 用装饰箭头替代因果含义 |
| 统计图与模型诊断 | Python、R、ECharts/Observable 的确定性导出 | 数据、单位、样本量、置信区间、编码与脚本可追溯；使用色盲友好配色 | 无数据造柱状图、折线图或显著性 |
| 地图、空间分布 | GIS、可追溯底图与数据 | 记录坐标系、比例尺、图例、数据年份和边界来源 | 图片模型生成真实地理边界 |
| 数学、几何、函数 | LaTeX、TikZ、GeoGebra、Matplotlib | 符号与正文一致，标出条件和尺度，尽量保持矢量 | 图片模型书写公式或刻度 |
| 电路、化学结构 | KiCad、Circuitikz、ChemDraw、RDKit 等领域工具 | 元件、键、方向和编号来自真实设计或化学结构 | 生成式模型猜测连接关系 |
| 生物机制、材料机理 | 图片模型底图加 SVG 标注，或 BioRender 类确定性组件 | 先写事实清单与空间关系；生成无字底图；后加标签、箭头和图例；明确“机制示意” | 冒充显微图或实验证据 |
| 实验装置、工艺剖面 | 有图片能力：详细 Prompt + 图片生成概念示意；复现工程另附 CAD | 标明入口、出口、部件、方向和关键尺寸；概念示意与可复现工程图明确分开 | 生成不存在的仪器读数和型号 |
| 教育或科普场景插画 | 图片模型 | 控制人物、场景、视角和留白；事实标签后置叠加 | 把插画当研究结果 |
| 原始照片、显微图、医学影像 | 原始科研文件 | 保留来源、采集参数、比例尺、脱敏和处理记录 | 生成、补画或无披露增强证据区域 |

## 快速判断

当前 Agent 具备图片生成能力时，流程、架构、框架、组织、ER/UML、机制、装置和场景类图走生成式图片路径，并用详细 Prompt、图片编辑和逐项验收保证连接与关系正确；只有数据统计图、原始科研影像以及公式、化学、电路、地图等领域图保持代码、原始证据或专业工具路径。当前 Agent 没有图片生成能力时，结构类图才回退确定性 SVG。
