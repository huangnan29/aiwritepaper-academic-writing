# 学术配图分类与攻略

| 图类 | 首选路径 | 关键攻略 | 禁止做法 |
| --- | --- | --- | --- |
| 研究流程、业务流程、算法流程 | SVG、Graphviz、Mermaid 后精修 | 先定义起止、步骤、判断、回路和异常路径；主路径单向；判断出口有标签 | 图片模型直接生成带字流程图 |
| 组织架构、模块分解 | SVG、Graphviz | 自上而下，同层同尺寸，汇报线与协作线使用不同线型 | 用面积或颜色暗示不存在的权重 |
| 软件架构、部署、网络拓扑 | SVG、C4、PlantUML | 分层、边界、协议、数据流分开表达；一张图只讲一个视角 | 把代码目录树当系统架构图 |
| 数据库 ER 图 | Mermaid ER、PlantUML、Graphviz、SVG | 依据真实 schema；标明主键、外键、基数和可空性；实体过多时拆分 | 根据正文想象表和关系 |
| UML 用例、类、状态、时序 | PlantUML、Mermaid、SVG | 严格使用对应语法；时序图时间向下；状态图列守卫条件 | 混用图法或省略关键参与者 |
| 研究框架、概念模型、因果图 | SVG、Graphviz | 区分构念、观测变量、假设方向、调节和中介；图中关系必须能回到文献或研究假设 | 用装饰箭头替代因果含义 |
| 统计图与模型诊断 | Python、R、ECharts/Observable 的确定性导出 | 数据、单位、样本量、置信区间、编码与脚本可追溯；使用色盲友好配色 | 无数据造柱状图、折线图或显著性 |
| 地图、空间分布 | GIS、可追溯底图与数据 | 记录坐标系、比例尺、图例、数据年份和边界来源 | 图片模型生成真实地理边界 |
| 数学、几何、函数 | LaTeX、TikZ、GeoGebra、Matplotlib | 符号与正文一致，标出条件和尺度，尽量保持矢量 | 图片模型书写公式或刻度 |
| 电路、化学结构 | KiCad、Circuitikz、ChemDraw、RDKit 等领域工具 | 元件、键、方向和编号来自真实设计或化学结构 | 生成式模型猜测连接关系 |
| 生物机制、材料机理 | 图片模型底图加 SVG 标注，或 BioRender 类确定性组件 | 先写事实清单与空间关系；生成无字底图；后加标签、箭头和图例；明确“机制示意” | 冒充显微图或实验证据 |
| 实验装置、工艺剖面 | CAD/矢量优先，复杂自然形态可用生成式底图 | 标明入口、出口、部件、方向、关键尺寸；需要复现时必须使用工程图 | 生成不存在的仪器读数和型号 |
| 教育或科普场景插画 | 图片模型 | 控制人物、场景、视角和留白；事实标签后置叠加 | 把插画当研究结果 |
| 原始照片、显微图、医学影像 | 原始科研文件 | 保留来源、采集参数、比例尺、脱敏和处理记录 | 生成、补画或无披露增强证据区域 |

## 快速判断

只要图中“连接、数值、符号、坐标或关系”必须逐项正确，就走确定性路径。只有自然形态、空间氛围或复杂材质是主要价值，并且图被明确视为示意而非证据时，才走生成式图片路径。
