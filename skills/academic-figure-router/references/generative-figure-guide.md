# 生成式学术插画攻略

## 先写事实契约

生成前建立一页图形事实契约：图的论点、必须出现的对象、对象之间的方向与层级、允许抽象的部分、不能改变的术语、不可生成的证据性细节。事实契约应能由正文、研究材料或可信文献逐条支持。

当客户端已暴露图片生成工具时，不要等待 shell 探测把能力写成 `AVAILABLE` 才调用。先从正文选取一张非证据性概念示意，使用内置工具生成并保存真实位图，再把产物和工具调用写入能力报告与图表清单。Codex 默认使用内置 `imagegen`/`image_gen`；只有用户明确选择 API/CLI 时才切换后端。

## 推荐构图方式

- 机制示意：左到右表示阶段，上下表示层级；同一对象跨阶段保持外观一致。
- 实验装置：侧视或等轴测，保留部件间空隙；文字与编号留给后处理。
- 材料或生物过程：用有限的放大窗展示微观层，不复制真实显微纹理。
- 多阶段过程：每个阶段一个清晰区域，避免用漂浮图标和无意义光效填空。
- 精确流程图：先列出节点与边的不可变清单，再指定单一阅读方向、节点形状、分支标签和出版风格；图片生成后逐项比对，禁止模型自行补节点或改写中文。

## 提示词模板

```text
用途：论文中的概念示意图，不是实验观测结果
核心命题：<一句话>
必须出现：<对象与数量>
空间关系：<位置、方向、层级、阶段>
视觉样式：克制的学术插画，白色或透明背景，有限配色，清晰边缘
构图：<横向/纵向/剖面/等轴测>，为后续中文标签预留留白
精确文字：不在底图中生成文字
必须避免：数字、坐标、品牌、水印、伪造仪器读数、装饰性粒子、错误连接
核对清单：<逐项列出可验证事实>
```

## 精确流程图提示词模板

```text
用途：论文中的精确流程图，由图片生成工具绘制，不是数据结果
核心命题：<一句话>
画布：<16:9/4:3/竖版>，白底，<从左到右/从上到下>
节点总数：<N，必须恰好等于 N>
节点清单：
1. <ID>｜形状：<矩形/圆角矩形/菱形>｜逐字标签：“<中文>”｜层级/分组：<...>
边清单：
1. <起点 ID> → <终点 ID>｜标签：“<条件或动作>”｜线型：<实线/虚线>
视觉样式：克制、精美、论文出版级、统一网格、有限配色、清晰边缘
字体与文字：中文清晰，无乱码、无错别字；只使用节点清单中的文字
必须避免：新增或遗漏节点、改变箭头方向、合并分支、装饰性图标、3D、发光、水印、品牌
验收清单：节点数、逐字标签、每条边、每个分支条件、阅读方向、留白、可读性逐项核对
```

每张流程图必须从正文、代码或流程材料填充以上模板，保存为独立 Prompt 文件后再调用图片工具。输出不满足任一精确项时使用图片编辑工具修正；若仍失败，标记 `FAIL` 或 `VISUAL_QA_BLOCKED`，不得静默改交纯 SVG。

## 后处理

在 SVG、Figma、Illustrator 或等价工具中加入最终文字、箭头、编号、比例说明和图例。中文字体嵌入或转路径前保留可编辑源；导出后检查 100% 与论文实际缩放尺寸下的可读性。
