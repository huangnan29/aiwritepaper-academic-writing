# 学术配图路由

先确定图要证明什么，再决定怎么画。具备图片生成能力时，结构图和概念图必须逐张调用图片工具；数据统计图仍从真实数据用代码生成。不要因为当前模型能写 SVG，就把纯 SVG 当成默认交付。

## 启动检查

1. 从正文、大纲、证据矩阵和图表清单提取图片目的、必须表达的节点或变量、来源、正文引用位置和交付格式。
2. 将能力拆成三层：当前语言模型是否原生输出图片、当前客户端是否暴露图片生成工具、本次运行是否实际调用并保存了图片。客户端活动 Skill/工具列表明确出现图片工具时，第二层直接记为已暴露；不能因为 shell 探测不到就标记缺口并回退 SVG。
3. 按 [references/figure-taxonomy.md](references/figure-taxonomy.md) 选择图类和后端，并按 [references/route-contract.md](references/route-contract.md) 写出机器可读的路由结果。当前客户端有图片生成能力且存在流程、架构、框架、组织、ER/UML、机制、装置或场景图时，必须读取 [references/generative-figure-guide.md](references/generative-figure-guide.md)。
4. 当前项目各模型和客户端的已核验边界见 [references/model-capability.md](references/model-capability.md)。该文件是时间敏感快照，执行前应复核实际工具。

## 路由原则

- 流程图、组织架构图、软件架构、ER 图、UML、研究框架、因果图和时间线：当前客户端有图片生成能力时，必须从上下文生成详细 Prompt 并逐图调用图片工具；`$academic-svg-enhancer` 只用于无图片能力环境或生成后的文字/箭头确定性修正层。
- 柱状图、折线图、散点图、热图、森林图和统计模型诊断图：从明确数据与分析脚本生成，不使用图片模型，也不手填数据点。
- 显微图、医学影像、实验照片、遥感图和仪器截图：使用原始文件并保留出处；生成式模型只能用于明确标注的“概念示意”，不能伪装成观测结果。
- 生物机制、材料机理、实验装置剖面、抽象过程场景和需要自然形态的科普示意：可用图片生成模型制作底图，但关键标签、箭头、比例尺和图例应在后处理层确定性叠加。
- 对材料机理、生物机制、实验装置、软件系统、管理流程和研究框架，只要客户端有图片生成能力，均应选择适合的学术视觉形式调用图片模型；不得因内容抽象就默认使用 SVG。
- 数学函数、几何、化学结构、电路原理和地图：使用领域工具或确定性绘图，避免生成式图片造成符号、连接或空间关系错误。

## 生成式图片执行规则

- 优先使用当前环境提供的内置图片工具；只有用户明确要求 API/CLI 路径时才使用相应模型接口。
- `FULL_BUILD` 或 `FIGURES_ONLY` 中，当前客户端暴露图片工具且用户未明确退出、期刊未禁止时，所有适合图片生成的计划图都必须逐张真实生成。Codex 优先调用内置 `imagegen`/`image_gen`；不得用 SVG、HTML 截图、占位 PNG 或“平台理论支持”代替真实调用。
- 软件、管理、教育和人文论文也要检查应用场景、用户交互、服务生态或概念情境是否适合作为生成式图像；不要把“没有生物或材料形貌”误判成整篇论文都不适合 image-gen。
- 提示词必须包含图的用途、事实清单、构图、视觉层级、精确文字、禁止项和可验证项目。不要把论文整段原文直接当提示词。
- 文字密集图的 Prompt 仍要列出逐字标签、节点和连线。先要求图片模型直接生成；若文字或箭头存在局部错误，优先使用图片编辑工具修正，必要时再用 SVG/排版层作确定性覆盖，但不能把覆盖层当作未调用图片模型的理由。
- 至少生成一个草图并检查语义，再生成终稿。每轮只修一个主要问题，防止整体漂移。
- 不生成不存在的实验结果、样本、病灶、显微结构、仪器读数、地理边界或统计趋势。

## 交付契约

每张图至少保留：

- 可编辑源文件或最终提示词；
- 论文嵌入用 PNG，并记录最终物理宽度、像素宽高与有效 DPI；最终有效分辨率不低于 300 DPI；
- 存在确定性文字/箭头修正层时保留对应 SVG 或 PDF；
- 图号、图题、正文首次引用位置、数据或事实来源；
- `generation_method`、`model_or_tool`、`prompt_file`、`human_verified` 和 `limitations`；
- 若为生成式图片，在图注或清单中明确标记“概念示意”或“AI 辅助绘制”，不得暗示为实测图。
- `figures/figure-manifest.json` 必须包含 `image_generation_policy`，记录客户端工具暴露、适合生图的全部图号、是否强制、`prompt_by_figure`、`generated_by_figure` 以及唯一允许的豁免原因。任一 `eligible_figure_id` 缺独立详细 Prompt 文件或真实生成位图即为 `FAIL`。

## 验收

逐项检查事实与结构正确、文字无误、视觉层级清楚、缩放后可读、无裁切、无水印、无多余装饰、图注与正文一致。不能验证的图片不得进入最终论文，只能进入待审目录。
