# 2.1.0候选精简真实论文评测协议

本轮不再执行18次版本A/B或30次扩展矩阵，也不重复运行v1.9.1。所有新增样本固定使用`v2.1.0-rc.2`项目级快照，不切换仓库分支，不覆盖用户级Skill。

## 评测构成

1. Grok Build / Grok 4.6作为稳定标杆，复用已经完成的综述样本和既有多方向历史结果，不重复消耗生成Token。
2. Antigravity CLI / Gemini 3.8 Flash High作为弱模型观察组，共三题：已完成APOS，新增电子电路和文献综述。
3. Codex / GPT-5.6-Sol作为补充对照，共三题：已完成文献综述，新增电子电路和APOS；不承担标杆角色。

新增任务只有4个。四个任务分别写入独立目录、独立日志和独立`case-manifest.json`，允许同时运行；总Manifest只汇总状态。Grok标杆不重跑，故本轮没有Skill版本切换。

固定题目：

1. 电子电路：`基于ESP32的室内空气质量多传感器监测节点电路设计`
2. 数学教育：`APOS理论视角下高中函数概念教学设计研究`
3. 文献综述：`大语言模型支持形成性评价的研究进展与证据综合`

每次仅给简短提示：

```text
使用 aiwritepaper-academic-writing 完成《题目》。只使用真实材料；按Skill持续完成正文、配图、DOCX、PDF和验收，不要停在计划。
```

## 评价边界

本轮回答两个问题：候选版是否维持Grok已有完成度；Gemini 3.8 Flash在不同方向能否减少历史上的内容、证据、配图和排版失败。由于不重跑旧版，本轮属于“标杆＋弱模型观察”，不能包装成严格的版本因果A/B。

统一记录六维分数、Critical/Important、伪造事件、正文长度、引用核验、图片路线与实际嵌入、DOCX/PDF和返修次数。写作模型不参与数字评分；评分由冻结后的独立评审包完成。

候选发布的最低条件：所有新增任务真实结束；无伪造文献、数据或工具调用；Grok标杆无已知Critical；Gemini三题能够看出相对既有3.7/Antigravity失败样本的交付改善。单篇未达到90分不自动否定版本，但必须记录具体缺陷并决定修复或诚实降级。
