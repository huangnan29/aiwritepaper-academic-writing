# 执行Profile：WEAK_MODEL

本Profile与唯一 `*-compact.md` 一起使用。不要再读取完整版提示词或公共规则目录。使用本最终提示词内嵌的阶段模板创建 `00-execution-checkpoints.json`，并把 `execution_profile` 改为 `WEAK_MODEL`。

严格按紧凑核心的九节执行，使用 `00-execution-checkpoints.json` 和阶段任务卡持续完成，不向用户逐阶段确认。每次只处理当前阶段；保存文件后立即核对存在性、数量和SHA-256，再进入下一阶段。

发生错误时：

- 文献/DOI/引用错误只回到证据阶段；
- 虚构数据或结果语气只回到数据来源和对应正文；
- ImageGen绕过或图文不符只回到图表阶段；
- LaTeX/OMML错误只回到公式与导出；
- 目录、表格缩进、题注、文件名只回到文档阶段；
- 状态冲突只重新运行受影响检查器和裁决器。

禁止“全面重写全文”式返修。已通过内容不得被低质量模板覆盖；ImageGen成功图不得被SVG覆盖；已核验文献不得被未核验来源替换；已存在OMML公式不得被纯文本重建。

若当前上下文接近上限，先写入阶段状态、文件路径、计数、未解决错误和下一动作，再继续；不得以输出一份计划代替实际交付。
