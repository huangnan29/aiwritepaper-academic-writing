# 范文结构分类与提示词体系

## 分类原则

AIWritePaper 首页主要按学科展示范文，但学科名称不足以决定论文方法。新 Skill 使用两级分类：先看研究对象和证据形态，再用学科规范细化章节、图表、伦理和质量门槛。

## 从范文归纳的结构家族

| 结构家族 | 对应公开范文 | 核心证据 |
|---|---|---|
| 软件工程 | 工学 | 源码、接口、数据库、日志 |
| 机械与电路工程 | 机械、电路 | 图纸、计算、仿真、测量 |
| 自然科学实验 | 物理、化学、实验期刊 | 样品、仪器、原始数据、统计 |
| 机器学习应用 | 信贷评分互动范文 | 数据集、特征、基线、训练日志和独立评估 |
| 管理与经济 | 管理、经济、工作报告 | 案例资料、公开数据、模型或过程证据 |
| 空间实证 | 地理 | 采样、空间数据、GIS工程 |
| 教育与数学教学 | 教育、理学 | 课程材料、参与者、量表或题目语料 |
| 艺术设计实践 | 艺术 | 调研、过程稿、原型、评价 |
| 法学规范分析 | 法学 | 现行法源、判例和权威解释 |
| 临床护理 | 医学 | 伦理、病例、干预和结局 |
| 人文文本研究 | 文学 | 权威文本、定位和竞争性解释 |
| 文献综合 | 文献综述 | 检索、筛选、质量评价和数据提取 |
| 通用期刊 | 期刊 | 已明确的方法、数据和期刊规范 |

## 为什么保留 19 个方向提示词

工程、机器学习、自然科学、医学和法学在证据、伦理和图表上差异很大，不能压缩成一个“理工科模板”。管理、经济、教育和艺术虽可能都使用案例或问卷，但研究对象、结果解释和外推边界不同。19 个方向在保持路由清晰的同时，共享能力、真实性、文献、输出和验收规则。

## 范文到提示词的转换原则

- 保留：章节组织、问题推进、图表类型和交付形态；
- 重写：研究问题、方法、证据和验收条件；
- 删除：无来源数字、未执行实验、虚构问卷、虚构实施结果、不可核验文献；
- 增补：证据状态、伦理、数据可用性、降级路径、同行评审和文件解析验收；
- 限制：完全通用提示词仅作兜底，正常运行只加载一个方向完整提示词。
