# 生成式学术配图规则

本规则处理图片能力 Agent 的论文配图。数据统计图由代码生成，原始科研影像使用原文件，公式、化学、电路和地图使用领域工具；流程、架构、ER、UML、研究框架、组织图、机制、装置和应用场景均通过详细 Prompt 调用图片模型生成，不能默认回退 SVG。

## 执行

1. 从正文和证据矩阵建立图形事实契约：核心命题、必须出现的对象、空间与方向关系、允许抽象的部分、不可改变的术语、不可生成的证据性细节。
2. 检查当前客户端的活动 Skill 与工具列表。若出现 Codex `imagegen`/`image_gen`、Grok Imagine、Nano Banana 或等价工具，记录 `client_tool_exposed=true`，不得因本地 shell 探测不到而跳过。
3. 在 `FULL_BUILD` 或 `FIGURES_ONLY` 中，客户端工具可用且用户未明确退出、期刊未禁止时，把所有适合生图的计划图列入 `eligible_figure_ids`，每张图独立编写 Prompt 并独立调用图片工具。精确流程图不得只给一句主题；必须写清节点原文、节点数量、分支条件、箭头起止、阅读方向、分组、层级、版式、配色、字体、禁止项和逐项核对表。
4. 将每张最终图片复制到项目 `figures/`，建立图号到 Prompt、工具、产物路径、文件摘要、限制与人工核对状态的一一映射。生成图中文字或箭头错误时，先用图片编辑工具定向修正；仍不准确时可叠加确定性文字/箭头修正层，但主视觉必须来自本次图片调用。
5. 逐项核对事实、节点数量、中文标签、箭头起止、分支条件、空间关系和禁止项。每次迭代只修一个主要问题。工具调用失败时记录真实错误与重试边界，不能静默改走纯 SVG。

## 提示词骨架

提示词应包含：论文用途、概念示意披露、核心命题、对象清单、空间关系、构图、克制的学术视觉样式、留白、精确文字策略、禁止项和核对清单。不得直接把论文整段正文丢给图片模型。

精确流程图 Prompt 额外必须包含：画布比例与阅读方向、节点总数、每个节点的逐字中文标签、节点形状、分组与层级、每条箭头的起点和终点、判断分支标签、主次路径、允许换行位置、颜色令牌、白底出版风格、不得新增/删减/改写节点与连线，以及输出后逐项比对的验收表。

## 禁止

不得生成不存在的样本、病灶、显微结构、实验结果、仪器读数、统计趋势、地理边界或品牌型号。生成式图片只能标为“概念示意”或“AI 辅助绘制”，不能暗示为实测证据。
