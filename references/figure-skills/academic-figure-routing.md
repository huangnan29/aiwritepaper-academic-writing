# 生成式学术配图规则

本规则只处理需要自然形态、复杂材质或空间场景的概念示意。流程、架构、ER、UML、统计图、公式、电路和地图不要使用图片模型。

## 执行

1. 从正文和证据矩阵建立图形事实契约：核心命题、必须出现的对象、空间与方向关系、允许抽象的部分、不可改变的术语、不可生成的证据性细节。
2. 核实当前运行真实存在的图片工具和模型。平台另有图片产品但本次不可调用时标记 `CAPABILITY_GAP`。
3. 只有自然形貌确实是主要信息时才生成无字或少字底图；需求未确认时默认抽象 SVG。为中文标签和指示线留白；最终文字、箭头、编号、比例和图例在确定性排版层加入。
4. 逐项核对事实、对象数量、空间关系和禁止项。每次迭代只修一个主要问题。

## 提示词骨架

提示词应包含：论文用途、概念示意披露、核心命题、对象清单、空间关系、构图、克制的学术视觉样式、留白、精确文字策略、禁止项和核对清单。不得直接把论文整段正文丢给图片模型。

## 禁止

不得生成不存在的样本、病灶、显微结构、实验结果、仪器读数、统计趋势、地理边界或品牌型号。生成式图片只能标为“概念示意”或“AI 辅助绘制”，不能暗示为实测证据。
